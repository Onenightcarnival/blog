# 第零世界从我的账单开始

今天看到一个说法叫"第零世界"：只有 10% 的人——硅谷那批——拥有最强的模型和资源，独立构成一个经济体，内部增速 50% 以上，把剩下的人挡在生产体系外面。

我看到这个词的第一反应不是震惊，是认出来。因为这堵墙我已经摸到了，它不在硅谷，在我的信用卡账单上。

## 我在付费上班

我是愿意为最强模型付费的那种人。最早 token 很贵的时候我就在付，因为它真的把我变成了 10x——我是靠 AI 第一批跑到 10x 的程序员之一。这笔投入对我来说从来不亏。

但有个细节一直拧巴：公司不报销这笔订阅费。

也就是说，我每天用来干活的最大杠杆，是我自己掏钱买的。公司的账本里没有这一项。我在付费上班。

听起来荒诞，但顺着想下去其实很自然。生产力的杠杆已经从"公司给你配的工具"转移到了"你自己为自己购买的算力"，而雇佣关系的账本还停在旧时代——它还以为它在买我的时间，没意识到真正干活的那部分，是我自费请来的。

## token 很值钱，只是你用错了尺子

有人会说，token 不是一直在降价吗，哪里值钱。

降价是真的，但那是用人类货币这把尺子量出来的。一美元能买多少 token，确实越来越多。

可你换一把尺子——一个 token 能买到多少"智能"、多少"被替代掉的人力"——结论就反过来了。模型每代都更强，同样一次调用换回来的产出在涨。用智能计价，token 不是在贬值，是在升值。

货币的保值靠的是稀缺加共识。token 看起来在通缩，单价一路趋零，但那只是名义价格。它的购买力——换算成智能——一直在涨。计价单位一换，整件事就立住了。这一步是关键，漏了它，下面全是空中楼阁。

## 模型之间有汇率

真正有意思的不是"模型像钱"，是模型之间存在汇率。

Claude 的 token 比别家贵，能力也更强。这就像美元：它自己也在通胀贬值，但放在所有货币里，它依然是硬通货，依然最值钱。强模型的 token 就是这个生态里的美元。

往下数，7B、30B 这些小模型的额度呢？给你一大把，你也换不到多少真正的产出。那是津巴布韦币——面额很大，购买力很低。

所以这不是单一货币的世界，是一个外汇市场。每个模型是一个币种，币值取决于它能换到多少智能。强模型升值，弱模型贬值，中间有实时汇率。你手里攥着哪个币种，决定了你的购买力。

## 所以以后干脆发 token 配额算了

这两年行业一直在降薪、裁员。顺着这个趋势推到底，结论有点冷：当劳动本身越来越多地被模型干掉，工资这个形态可能就不成立了。

公司为什么要发钱买你的时间？你的时间产出正在被模型替代。它真正需要分配的，是"调用智能的权力"。

所以未来的报酬形态可能会变：不发工资，发 token 配额。给你多少最强模型的额度，就等于给你多少生产力，等于给你多少钱。

发美元（Claude 额度）还是发津巴布韦币（小模型额度），就是新的薪资谈判。

## 墙是从账单长出来的

回到第零世界。

我们容易以为那堵墙是 10% 的人主动垒起来的——他们囤积了模型，把别人关在外面。但从我的账单看，事情是反过来的：没有人画那条线，是"谁能持续付得起最强那一档"自动把人分了层。

模型权重可以复制，开源会一路追平，这些都对。但最前沿那一档的访问权和算力配额，永远稀缺，永远要钱。墙不在模型本身，在持续支付能力上。

而这堵墙最早出现的地方，不是什么宏大的经济结构，是一个像我这样的人，对着一张公司不肯报销、但自己舍不得停的订阅账单。

第零世界不是从硅谷开始的。是从我的账单开始的。
